# Submission checklist

Deadline: **August 14, 2026 at 4:00 PM PDT** — **6:00 PM CDT**.

## Required account actions

- [ ] Join the challenge on Devpost.
- [ ] Complete the Arm Developer Program registration using the same email.
- [ ] Confirm individual/team eligibility and designate a representative if a
  team is submitting.
- [ ] Select **Physical AI** as the track.

## Required repository actions

- [ ] Publish the final branch to the public GitHub repository.
- [ ] Merge the competition PR before submitting the repository URL.
- [ ] Confirm `LICENSE` is visible and set the GitHub About license to Apache
  2.0 if GitHub does not detect it automatically.
- [ ] Verify setup from a fresh clone or container.
- [ ] Confirm no secrets, personal audio, or generated databases are tracked.

## Devpost fields

- [ ] Project name and tagline from [`SUBMISSION.md`](SUBMISSION.md).
- [ ] Physical AI track selected.
- [ ] Full English write-up pasted and proofread.
- [ ] Public repository URL added.
- [ ] Technologies list added: Arm64, whisper.cpp, Python, FastAPI, SQLite,
  Docker, JavaScript.
- [ ] At least one dashboard screenshot uploaded.
- [ ] Native Arm64 benchmark screenshot or evidence image uploaded.
- [ ] Public under-three-minute demo video URL added.
- [ ] Explain that the project was created/significantly updated during the
  submission period.

## Final judge simulation

- [ ] Signed-out browser can open the repository and video.
- [ ] README states what changed, why it matters, and measured before/after
  results above the fold.
- [ ] A judge can find setup, expected output, benchmark method, raw evidence,
  hardware, dependencies, and limitations in under two minutes.
- [ ] Demo shows real inference on Arm hardware and matches the submitted code.
- [ ] Devpost preview has no broken Markdown, cropped images, or private links.
- [ ] Submit early, then reopen the project page to confirm the entry is not
  still a draft.
